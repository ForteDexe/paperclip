# Outpost North Star

A North Star records why work matters beyond one task. It is optional for the
current workflow and is not required before normal task work.

Read North Stars when direction is relevant. Create, edit, or delete one only
when the human explicitly asks; do not infer a durable strategy from a routine
task description.

Read [references/api-reference.md](references/api-reference.md) for the small
API surface.
